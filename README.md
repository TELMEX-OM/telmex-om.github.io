# TELMEX OM — Portal de Presentaciones

Sitio: https://telmex-om.github.io/

## Estructura

```
index.html                      # Portal principal
assets/css/styles.css           # Estilos del portal
presentations/<categoría>/<AAAA-MM-DD-tema>/index.html
```

## Agregar una presentación

1. Crea `presentations/<categoría>/<AAAA-MM-DD-tema>/index.html`.
2. Agrega una tarjeta (`<a class="card">`) en `index.html`.
3. Si es una categoría nueva, agrega su botón en `.filters`.
4. Commit y push a `main`.
